# StoryFork без каталога ассетов

Первый запрос к модели планирует непрерывную локацию, свет, пол и позиции событий. Второй рисует геометрию и выделяет поверхности. Третий рисует для этих поверхностей повторяемые SVG-узоры и отдельные детали, которые обрезаются по контурам поверхностей. Инструкции генератора на английском, сцену можно описать на русском. Локация занимает от одного до восьми экранов по 1600 × 900. Камера сохраняет пропорции 16:9 и по умолчанию приближена в 1.8 раза: персонаж занимает около трети высоты кадра. Ползунок «Приближение» меняет масштаб от общего плана 1× до 2.4×; во время диалога кадр учитывает собеседника. В превью можно пройти маршрут, вернуться по шкале времени, скрыть слои и скачать всю панораму.

Глубина строится крупными тональными плоскостями, перекрытиями и тенями. Швы и фактура тонкие, приглушённые и могут отсутствовать: обязательного минимума деталей нет. Яркие акценты привязаны к источникам света; повторяемые узоры не должны превращать потолок и пол в контрастную сетку. Эти настройки применяются при новой генерации сцены.

План содержит `visualBrief`: тип локации и материалы, освещение по описанию, а также список всех видимых ориентиров с координатами и характерными формами. Он передаётся этапам рисунка, объектов и фактуры и сохраняется в JSON сцены. Лес строится силуэтами деревьев и рельефом уже на этапе рисунка; узоры не заменяют геометрию. Ясный полдень сохраняет дневную экспозицию даже в холодных тенях.

`POST /api/scenes` принимает `brief`, необязательный `screens` (по умолчанию 1) и событие `beat: { cue, screen }`. Для прохода из сценария можно передать `travel` с переходами `{ cue, from, to, departureAt, arrivalAt }` и `beats` с событиями `{ at, cue, screen }`. Без готового маршрута модель может добавить до шести промежуточных точек между `start` и `end`: объекты остаются у своих ориентиров, а персонаж проходит точки по порядку и останавливается для взаимодействий. Если модель привязала открытие преграды к отсутствующему событию, оно выполняется при подходе вместо молчаливого пропуска. Кнопка «Проход из сценария» использует сохранённый пример мастер-агента. Координаты мира имеют масштаб 160 × 90 на экран, время переходов задаётся в секундах.

Для действий из сценария можно передать `objectScript: { objects, commands }`. Когда его нет, модель сама выделяет интерактивные объекты из описания. Объект задаётся как `{ id, label, kind, anchor, initial }`. `anchor` — точка маршрута, для обычной сцены это `start`, `end` или промежуточная точка у ориентира. Типы `door`, `gate` (подъёмная решётка) и `barrier` (поворотный шлагбаум) имеют состояния `closed` / `open`, у `light` (лампа) и `sunlight` (естественный солнечный луч) есть `on` / `off`. У шлагбаума нет непрозрачного дверного проёма: вращается только узкая перекладина. У `sunlight` гаснут луч и солнечное пятно, а дневное освещение фона сохраняется. Без временного события луч остаётся в исходном состоянии. Модель рисует неподвижные и подвижные части каждого объекта отдельными SVG-группами.

| Команда | Поведение |
| --- | --- |
| `{ op: "change", target, state, at, duration }` | Плавно переводит объект в указанное состояние и оставляет в нём. |
| `{ op: "loop", target, state, at, duration, period }` | Чередует текущее и указанное состояния до следующей команды для этого объекта. `duration` — длина каждого перехода. |
| `{ op: "interact", target, state, at, duration }` | Персонаж тянется к ручке или выключателю и запускает переход после касания. Он должен стоять у объекта до конца жеста. |

Все времена в секундах, `target` — ID объекта. «Проход из сценария» показывает ветку с подъёмом решётки. Лампа у окна сначала мигает и гаснет на исходном сюжетном событии. Перемотка пересчитывает положение и свет для выбранного времени. SVG сохраняет текущий кадр панорамы, JSON содержит движущиеся части, состояния и команды для воспроизведения.

Из корня репозитория, с Node.js 22.9 или новее:

```sh
cp -n hypothesis-non-production/test_no_asset/.env.example hypothesis-non-production/test_no_asset/.env
```

Установите зависимости через `npm --prefix hypothesis-non-production/test_no_asset ci`. По умолчанию `.env.example` выбирает Google Cloud Gemini: `LLM_PROVIDER=vertex`, `GOOGLE_CLOUD_PROJECT`, `GOOGLE_CLOUD_LOCATION=global` и `GEMINI_MODEL=gemini-3.5-flash`. Укажите свой ID проекта. Для локальной авторизации выполните `gcloud auth application-default login`. SDK читает ADC из стандартного расположения и обновляет токены автоматически. Ключ API не нужен. В этом режиме все этапы используют только Google Cloud Gemini, даже если в окружении остались ключи других провайдеров.

Выполните `npm --prefix hypothesis-non-production/test_no_asset start` и откройте [превью](http://127.0.0.1:8790/). Скрипт запуска также читает `hypothesis-non-production/test/.env`, а значения из `hypothesis-non-production/test_no_asset/.env` имеют приоритет.

Для прежнего маршрутизатора удалите `LLM_PROVIDER=vertex` и добавьте ключи `NVIDIA_API_KEY`, `GROQ_API_KEY` или `GEMINI_API_KEY` в `hypothesis-non-production/test_no_asset/.env`. Достаточно одного ключа.

После постановки отдельный этап `panorama_sound` выбирает звуковой фон и материал шагов параллельно с рисунком и объектами. Результат сохраняется в `scene.sound`: `{ version: 1, ambience, surface, ambienceGain, stepsGain }`, уровни от 0 до 1. Фоны: `room`, `industrial`, `city`, `forest`, `night`, `wind`, `rain`, `water`. Поверхности: `concrete`, `tile`, `metal`, `wood`, `grass`, `gravel`, `carpet`, `snow`. При ошибке модели используется локальный подбор по описанию; в списке этапов он отмечен как `procedural-fallback`.

Звук синтезируется в браузере через Web Audio: фильтрованный шум, медленная модуляция, редкие птицы или насекомые и три слоя каждого шага (пятка, корпус, подошва). Это компактная адаптация подхода из переданного `audio-engine.js`; Tone, Vite, аудиофайлы и отдельный сервер не нужны. Один шумовой буфер используется повторно, короткие голоса освобождаются после окончания. Фон и шаги запускаются кнопкой «Пройти сцену», шаги совпадают с двумя контактами ног за цикл анимации и отсутствуют на остановках. Пауза, перемотка, новая генерация и скрытие вкладки останавливают звук. Есть отключение звука и общая громкость. SVG остаётся статическим изображением, а JSON содержит звуковой план для повторного синтеза.

При наличии `OPENROUTER_API_KEY` все этапы идут через OpenRouter. Порядок задаётся списком `OPENROUTER_MODELS` через запятую. Роутер принимает только явные варианты `:free` и при ошибке пробует следующую модель из этого списка. При запуске с `OPENROUTER_API_KEY=` используются настроенные NVIDIA NIM, Groq и Gemini. Их модели можно задать переменными `NVIDIA_MODEL`, `GROQ_MODEL` и `GEMINI_MODEL`.

Проверки SVG, пропорций и переключения моделей запускаются через `npm --prefix hypothesis-non-production/test_no_asset test`.


Кнопка «Попробовать диалог вдвоём» добавляет к текущей сцене лесника и четыре реплики с жестами и подписями говорящего. Если сцены ещё нет, открывается локальный пример леса с вышкой без обращения к модели. Перемотка и кнопки реплик восстанавливают говорящего и позы по времени. Озвучивания реплик пока нет; фон и шаги продолжают работать.

Для собственного диалога `POST /api/scenes` принимает необязательный `dialogue`, который возвращается в JSON сцены:

```json
{
  "actors": [
    { "id": "mara", "name": "Мара", "skin": "kit" },
    { "id": "ranger", "name": "Лесник", "skin": "morgan", "x": 250 }
  ],
  "lines": [
    { "speaker": "mara", "text": "Ты слышал стук?", "at": 8, "duration": 3 },
    { "speaker": "ranger", "text": "Да, у старой вышки.", "at": 11.5, "duration": 3 }
  ]
}
```

Первый персонаж следует основному маршруту, остальные стоят в заданных мировых координатах. Допускается 2–4 персонажа и до 80 непересекающихся реплик. `at` и `duration` — секунды; `x` — единицы мира, 160 на экран. Невалидные реплики отклоняются до запуска генерации. Диалог пока задаётся явно либо кнопкой примера, а не извлекается автоматически из описания.


Для хвойных деревьев и охотничьих вышек этап рисунка возвращает массивы `trees` и `lookouts`. Модель задаёт размещение, размеры и палитру; `background-forms.mjs` строит связные SVG-части. У дерева отдельные ствол и крона с нерегулярными ярусами, у вышки — опоры, подкосы под площадкой, настил, перила, поддержанная крыша и лестница со ступенями. Это векторные формы без растровых ассетов. Старые JSON без этих полей по-прежнему открываются, но их недостающая геометрия сама не меняется: для нового фона нужна новая генерация. Локальный пример диалога уже содержит новые формы.
