# Гипотезы и эксперименты

Материалы для проверки идей и предыдущие прототипы. Продакшн находится в `../src/`, инструкции по запуску — в [корневом README](../README.md).

- `test/` — прототип на Phaser, лаборатория ассетов и проверки сцен.
- `test_no_asset/` — генератор SVG-сцен без готовых ассетов.
- `test_no_asset_before_animation/` — версия до анимации объектов.
- `actual_implementation/` — сценарные промпты, сравнения моделей и сохранённые результаты.
- `assets/` — экспериментальная библиотека графики и анимаций.
- `storyfork-pitch/final/` — презентационные материалы.

Команды в документации запускаются из корня репозитория. Относительные связи между прототипами сохранены. Зависимости устанавливаются отдельно в каталогах прототипов; локальные `.env`, `node_modules` и сборочные файлы в Git не входят.
